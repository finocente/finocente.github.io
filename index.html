🚀 Ejecutar la web en Termux

miservidor

La web corre en Termux con ./webapp.sh start (arranca Redis + Flask). Todo queda en ~proyectos/webapp_redis:

./webapp.sh start
curl http://localhost:5000

En el servidor también hay un panel de servicios (nginx) con Home Assistant, AdGuard, MediaServer y noVNC.

🔗 Tailscale · Conexión al servidor

Usa el servidor miservidor como base de datos en tiempo real (Redis) desde tus apps de GitHub. Con Tailscale instalado, apunta tus apps a esta dirección:

redis://100.118.45.14:6379 Instalar Tailscale ↗

💻 Acceso por SSH

Terminal directa al servidor Debian miservidor estés donde estés, dentro de la red Tailscale.

⚡ Cómo conectar desde una app

📲 Cliente

Instala Tailscale en tu móvil, PC o Termux e inicia sesión con tu cuenta. Ya verás el nodo miservidor (100.118.45.14) en tu red.

tailscale up

🐍 Ejemplo Python

Conecta a la base de datos en tiempo real desde tu app o script:

import redis
r = redis.Redis(host="100.118.45.14", port=6379)
r.set("hola", "mundo")
